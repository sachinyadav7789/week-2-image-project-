# Interactive Image Gallery — Week 2

A responsive image gallery built for the Week 2 Web Development assignment.

## Features
- 8 images displayed in a responsive grid
- Hover zoom and overlay animations
- Category filtering using JavaScript DOM manipulation
- Full-screen lightbox view
- Previous / next navigation
- ESC, Left Arrow and Right Arrow keyboard controls
- Responsive design for desktop, tablet and mobile
- Local SVG images, so the gallery works without an image CDN

## Technologies
HTML5 · CSS3 · JavaScript

## How to run
Open `index.html` in a browser.
